# SwiftShare

SwiftShareは、C# Windows Formsを使用して作成された、高機能かつ高速なローカルネットワーク向けファイル転送ツールです。
同一ネットワーク内のPCを自動検出し、直感的な操作でファイルやフォルダを双方向に送受信できます。

## 主な機能
- **自動ピア検出**: UDPマルチキャスト通信により、同一ネットワーク上の実行中のインスタンスを自動で見つけます。同じPC内での2重起動によるlocalhostテストにも完全対応しています。
- **タスクベースの履歴管理**: 転送を「タスク」単位で管理。個別のファイル進捗に加え、全体の進捗率、リアルタイムの転送速度(MB/s)を表示します。
- **高度な転送制御**: 転送中の**一時停止・再開・キャンセル**が可能です。
- **詳細なファイルツリー**: 各タスクを展開して、元のフォルダ構造とファイルごとの進捗状況を確認できます。
- **エクスプローラーライクな操作**:
    - **右クリックメニュー**: Copy, Paste, Delete, Download操作に対応。
    - **ショートカットキー**: Ctrl+C, Ctrl+V, Ctrl+D(削除), Deleteキーに対応。
    - **画面間コピペ**: リモート画面でコピーしてローカル画面に貼り付けることでダウンロード、その逆でアップロードが可能です。
    - **ドラッグ＆ドロップ**: 左右のパネル間、または外部エクスプローラーからのドロップで転送を開始できます。
- **レジストリ連携**: ウィンドウの分割比率を自動保存し、次回起動時に復元。Windows起動時の自動実行設定もメニューから切り替え可能です。
- **管理者権限対応**: システムドライブ等の保護されたフォルダへの書き込み・削除も可能です。
- **安全な削除機能**: 受信したファイルやリモートへ送ったファイルを、送信元（コピー元）を傷つけることなく消去できます。

## 使い方
1. `SwiftShare.exe` を起動します（管理者権限が要求されます）。
2. 同一ネットワーク内の他PCでアプリが起動すると、左側の「ONLINE PEERS」に自動で表示されます。
3. 相手を選択すると、右側に相手のファイル一覧が表示されます。
4. ファイルをドラッグ＆ドロップ、または Ctrl+C / Ctrl+V で転送を開始します。
5. 「RECENT ACTIVITY」で進捗を確認し、完了後は「Open」ボタンでフォルダを素早く開けます。

## 開発環境
- .NET Framework 4.0以上
- C# 5.0 (csc.exe 4.8.9221.0等でコンパイル可能)

## 注意事項
- ネットワーク環境によっては、Windowsファイアウォールの許可が必要です。
- 受信側と送信側の両方でこのアプリが起動している必要があります。
- **Delete**ボタンは、受信側では「保存されたファイル」を、送信側では「相手に送ったファイル」のみを削除します。元のソースファイルは削除されません。
