# FileTransferApp

このアプリは、C# Windows Formsを使用して作成された、シンプルなファイル送信ツールです。

## 機能
- **UDPによる自動検索:** 同一ネットワーク内の他PCを自動で見つけます。
- **TCPによるファイル転送:** ドラッグ＆ドロップしたファイルをTCP経由で送受信します。
- **デスクトップ保存:** 受信したファイルは自動的にデスクトップに保存されます。

## 使い方
1. Visual Studioで `FileTransferApp.csproj` を開きます。
2. アプリを起動します。
3. リストに相手のIPアドレスが表示されたら、それを選択します。
4. 送信したいファイルをウィンドウにドラッグ＆ドロップします。

## 注意事項
- ネットワーク環境によっては、Windowsファイアウォールの許可が必要です。
- 受信側と送信側の両方でこのアプリが起動している必要があります。
